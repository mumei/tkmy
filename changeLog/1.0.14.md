# TKMY 1.0.14

## English

- Choose weekly or short-term quota separately for Codex and Claude in Settings. Changes apply immediately and persist across launches.
- Claude can also show the separate Fable weekly quota returned by the official SDK. Missing or expired selected quotas show —; other windows and historical accounts are never substituted.
- Live Fable retrieval remains unverified on the development Mac (Claude Code 2.1.76). Retrieval requires the reviewed Claude Code 2.1.289+ contract and an eligible account.

## 日本語

- 設定でCodex・Claudeごとに週間枠または短時間枠を選べます。変更はすぐに反映され、次回起動時も保持されます。
- ClaudeではFable専用の週間枠も選べます。未取得・期限切れの枠は「—」と表示し、別の枠や過去アカウントの値では補いません。
- 開発MacのClaude Codeは2.1.76のため、Fableの実取得は未確認です。取得には確認済みの仕様に対応するClaude Code 2.1.289以降と対象アカウントが必要です。

- Der Live-Abruf von Fable ist auf dem Entwicklungs-Mac mit Claude Code 2.1.76 noch ungeprüft. Er erfordert Claude Code 2.1.289+ und ein geeignetes Konto.
