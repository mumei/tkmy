# TKMY 0.1.0

## English

### Initial release

- Visualize Codex and Claude Code token usage as separate menu bar meters.
- Review daily usage, estimated cost, model breakdowns, and a 12-month heatmap.
- Process usage records locally and switch the interface between 11 languages.
- Includes the TKMY app icon inspired by the token usage heatmap and meter.
- Includes the packaged-app startup fix.

## 日本語

### 初回リリース

- CodexとClaude Codeのトークン利用状況を、個別のメニューバーメーターで確認できます。
- 日別利用量、推定金額、モデル別内訳、直近12か月のヒートマップを表示できます。
- 利用記録をMac内で処理し、画面表示を11言語から選択できます。
- トークン利用量のヒートマップとメーターをモチーフにしたTKMYアプリアイコンを収録しています。
- 配布版アプリが起動できない問題の修正を含みます。

## Tiếng Việt

## ไทย

### รุ่นแรก

- แสดงการใช้โทเค็นของ Codex และ Claude Code แยกกันบนแถบเมนู
- ดูการใช้งานรายวัน ค่าใช้จ่ายโดยประมาณ รายละเอียดตามโมเดล และฮีตแมปย้อนหลัง 12 เดือนได้
- ประมวลผลข้อมูลภายในเครื่องและรองรับภาษาอินเทอร์เฟซ 11 ภาษา
- มีไอคอน TKMY ที่ออกแบบจากฮีตแมปและแถบวัดการใช้โทเค็น
- รวมการแก้ไขปัญหาการเปิดแอปเวอร์ชันเผยแพร่
