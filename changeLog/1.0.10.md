# TKMY 1.0.10

## English

- Added GPT-6.1 Sol to the bundled pricing catalog using its published Standard short-context rates. Cached input is $0.10 per million tokens, half the GPT-6 Sol rate.
- Added Claude Code's general remaining allowance to the menu meter and quota history. The 7-day window takes priority; a 5-hour window is labeled when it is the only available window. Context-window usage and model-specific limits are not combined with this allowance.
- Uses the existing Claude Code login through an experimental official SDK feature. This integration requires Claude Code 2.1.289 or later, the oldest contract reviewed here; this is not a claim about when the API was introduced. The API may change in future versions.
- Missing or unsupported CLI versions, unavailable login or profile scope, API-key sessions, third-party providers, and missing quota data display “—”. The existing percentage-display setting is respected.
- On a failed request, the last observation is retained for at most 10 minutes and never past its reset. A reset does not imply 100% remaining without a new observation.
- Validation: 14 Claude quota tests, related existing tests, and the local app build passed. Real-account retrieval remains unverified because this Mac has Claude Code 2.1.76.
