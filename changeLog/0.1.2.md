# TKMY 0.1.2

## English

### Memory usage improvements

- Fixed an issue where memory usage could exceed 1 GB after running TKMY for a long time with large Codex or Claude Code histories.
- Usage logs are now processed incrementally in fixed-size chunks instead of loading entire files into memory.
- Daily and model usage reports are now aggregated without retaining every raw event, and overlapping refresh requests are consolidated.

## 日本語

### メモリ使用量の改善

- 大量のCodex／Claude Code履歴がある環境で長時間稼働すると、メモリ使用量が1GBを超えることがある問題を修正しました。
- 利用ログ全体をメモリへ読み込まず、固定サイズの分割データと追記部分だけを処理するようにしました。
- 日別・モデル別集計で全イベントを保持しないようにし、重複する更新処理もまとめるようにしました。

## Deutsch

### Verbesserte Speichernutzung

- Ein Problem wurde behoben, durch das der Speicherverbrauch bei langer Laufzeit und umfangreichen Codex- oder Claude-Code-Verläufen auf über 1 GB steigen konnte.
- Nutzungsprotokolle werden nun schrittweise in Blöcken fester Größe verarbeitet, statt vollständige Dateien in den Speicher zu laden.
- Tages- und Modellberichte werden ohne dauerhafte Speicherung aller Rohereignisse erstellt; überlappende Aktualisierungen werden zusammengefasst.

## 简体中文

### 内存使用改进

- 使用日志现在按固定大小分块增量处理，不再将整个文件加载到内存中。
- 每日及模型用量报告不再保留全部原始事件，并会合并重复的刷新请求。
