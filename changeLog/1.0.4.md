# TKMY 1.0.4

## English

### Clearer cache metrics

- Removed the misleading Cache creation item from Codex details, because Codex logs do not provide a dedicated cache-creation value and it always showed 0. Cache creation remains available in Claude Code details.

## 日本語

### キャッシュ表示の改善

- Codexのログにはキャッシュ作成専用の値がなく常に0と表示されるため、誤解を招く「キャッシュ作成」をCodexの詳細画面から削除しました。Claude Codeの詳細画面では引き続き表示されます。

## Deutsch

### Klarere Cache-Anzeige

- Der irreführende Eintrag „Cache-Erstellung“ wurde aus den Codex-Details entfernt, da Codex-Protokolle keinen eigenen Wert für die Cache-Erstellung enthalten und deshalb immer 0 angezeigt wurde. In den Claude-Code-Details bleibt die Cache-Erstellung sichtbar.

## 简体中文

### 更清晰的缓存指标

- Codex日志不提供专用的缓存创建数值，因此该项始终显示为0。我们已从Codex详情中移除容易引起误解的“缓存创建”项；Claude Code详情中仍会显示该项。

## Français

### Indicateurs de cache plus clairs

- L’élément trompeur « Création du cache » a été retiré des détails Codex, car les journaux Codex ne fournissent pas de valeur dédiée et il affichait toujours 0. La création du cache reste affichée dans les détails Claude Code.

## 한국어

### 더 명확해진 캐시 표시

- Codex 로그에는 캐시 생성 전용 값이 없어 항상 0으로 표시되므로, 혼동을 줄 수 있는 ‘캐시 생성’ 항목을 Codex 상세 화면에서 제거했습니다. Claude Code 상세 화면에서는 계속 표시됩니다.

## Español

### Métricas de caché más claras

- Se eliminó de los detalles de Codex el elemento confuso «Creación de caché», ya que los registros de Codex no proporcionan un valor específico y siempre mostraba 0. La creación de caché sigue mostrándose en los detalles de Claude Code.

## Italiano

### Metriche della cache più chiare

- L’elemento fuorviante «Creazione cache» è stato rimosso dai dettagli di Codex, perché i log di Codex non forniscono un valore dedicato e mostrava sempre 0. La creazione della cache continua a essere visualizzata nei dettagli di Claude Code.

## Tiếng Việt

### Chỉ số bộ nhớ đệm rõ ràng hơn

- Đã xóa mục «Tạo bộ nhớ đệm» dễ gây hiểu lầm khỏi phần chi tiết Codex, vì nhật ký Codex không có giá trị riêng cho việc tạo bộ nhớ đệm nên mục này luôn hiển thị 0. Mục này vẫn được hiển thị trong phần chi tiết Claude Code.

## ไทย

### ตัวชี้วัดแคชที่ชัดเจนขึ้น

- ได้นำรายการ «การสร้างแคช» ที่อาจทำให้เข้าใจผิดออกจากรายละเอียดของ Codex เนื่องจากบันทึกของ Codex ไม่มีค่าเฉพาะสำหรับการสร้างแคช จึงแสดงเป็น 0 เสมอ ทั้งนี้ รายการการสร้างแคชยังคงแสดงอยู่ในรายละเอียดของ Claude Code

## 繁體中文

### 更清楚的快取指標

- Codex記錄並未提供專用的快取建立數值，因此該項目一直顯示為0。我們已從Codex詳細資訊中移除容易造成誤解的「快取建立」項目；Claude Code詳細資訊中仍會顯示此項目。
