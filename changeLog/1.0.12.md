# TKMY 1.0.12

## English

- Codex and Claude Code now show the 5-hour and weekly remaining allowances together: blue for 5 hours and orange for the week. Each legend entry shows the last confirmed value and time; all six chart periods remain available.
- Added an account picker. Claude history is separated by email and organization ID; Codex history is separated by email. Historical accounts show values at their last observation, and older anonymous history remains in an unknown-account group.
- Account identity is checked before and after quota retrieval, and switching accounts clears the previous account's cache. Missing values are not treated as 0% or 100%. Authentication tokens, API keys, and raw authentication responses are not stored or logged.
- Codex workspaces sharing one email cannot be distinguished through the public protocol. Token-per-percentage estimates are unavailable for account-specific history because local token logs cannot be reliably assigned to an account. These are Codex allowances, not ChatGPT chat limits.
- Regression tests, synthetic screen checks, and the local build passed. Live multi-account/organization switching and real Claude quota retrieval remain unverified. Claude Code 2.1.289 or later is still required for quota retrieval.

## Tiếng Việt

- Codex và Claude Code hiển thị đồng thời hạn mức còn lại trong 5 giờ và theo tuần: màu xanh cho 5 giờ, màu cam cho tuần. Chú giải có giá trị và thời điểm xác nhận gần nhất; vẫn giữ đủ sáu khoảng thời gian biểu đồ.
- Thêm bộ chọn tài khoản. Lịch sử Claude được tách theo email và ID tổ chức; lịch sử Codex theo email. Tài khoản cũ hiển thị giá trị ở lần ghi nhận cuối, còn lịch sử ẩn danh trước đây nằm trong nhóm tài khoản không rõ.
- Kiểm tra tài khoản trước và sau khi đọc hạn mức. Khi đổi tài khoản, bộ nhớ đệm của tài khoản trước được xóa. Dữ liệu chưa có không được coi là 0% hay 100%. Không lưu hoặc ghi log token xác thực, khóa API hay đầu ra xác thực thô.
- Giao thức công khai không phân biệt được các workspace Codex dùng chung email. Không ước tính số token cho mỗi điểm phần trăm trong lịch sử theo tài khoản vì không thể gán chắc chắn log token cục bộ cho tài khoản. Đây là hạn mức Codex, không phải giới hạn trò chuyện ChatGPT.
- Các bài kiểm thử hồi quy, kiểm tra giao diện bằng dữ liệu tổng hợp và bản dựng cục bộ đều đạt. Chưa xác minh việc đổi giữa nhiều tài khoản/tổ chức thật hay truy xuất hạn mức Claude thật. Vẫn cần Claude Code 2.1.289 trở lên để đọc hạn mức.

## ไทย

- Codex และ Claude Code แสดงโควตาคงเหลือแบบ 5 ชั่วโมงและรายสัปดาห์ในกราฟเดียวกัน โดยใช้สีน้ำเงินสำหรับ 5 ชั่วโมงและสีส้มสำหรับรายสัปดาห์ คำอธิบายกราฟแสดงค่ากับเวลาที่ยืนยันล่าสุด และยังเลือกช่วงเวลาได้ครบทั้งหกแบบ
- เพิ่มตัวเลือกบัญชี ประวัติ Claude แยกตามอีเมลและ ID องค์กร ส่วนประวัติ Codex แยกตามอีเมล บัญชีก่อนหน้าจะแสดงค่าเมื่อเก็บข้อมูลครั้งล่าสุด และประวัติเดิมที่ไม่มีข้อมูลบัญชียังคงอยู่ในกลุ่มไม่ทราบบัญชี
- ตรวจสอบบัญชีก่อนและหลังอ่านโควตา และล้างแคชของบัญชีก่อนเมื่อเปลี่ยนบัญชี ค่าที่ยังไม่ได้รับจะไม่ถูกนับเป็น 0% หรือ 100% ไม่บันทึกโทเค็นยืนยันตัวตน คีย์ API หรือผลลัพธ์การยืนยันตัวตนดิบลงฐานข้อมูลหรือ log
- โปรโตคอลสาธารณะไม่สามารถแยก workspace ของ Codex ที่ใช้อีเมลเดียวกันได้ ประวัติรายบัญชีจึงไม่ประมาณจำนวน token ต่อโควตา 1% เพราะไม่สามารถระบุบัญชีเจ้าของ log token ในเครื่องได้แน่นอน โควตาที่แสดงเป็นของ Codex ไม่ใช่ข้อจำกัดแชตของ ChatGPT
- การทดสอบถดถอย การตรวจหน้าจอด้วยข้อมูลจำลอง และการ build ในเครื่องผ่านแล้ว ยังไม่ได้ตรวจสอบการสลับบัญชี/องค์กรจริงหรือการอ่านโควตา Claude จริง การอ่านโควตายังคงต้องใช้ Claude Code 2.1.289 ขึ้นไป
