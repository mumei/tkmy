# TKMY 1.0.15

## English

- Added settings for separate Claude account folders and for choosing the folder supplying the menu-bar quota. Successful readings from all configured folders are saved in account-separated history; missing selected data never falls back to another account.
- Improved account checks when reading quotas to reduce incorrect attribution. History follows the current account by default while preserving explicit historical selections.
- Requires existing signed-in Claude configuration folders and Claude Code 2.1.289 or later.

## 日本語

- 既存のClaude設定フォルダをアカウント別に指定し、メニューバーに表示するフォルダを選べます。各フォルダから取得した残量は、アカウント別の履歴に保存します。未取得の値を別アカウントの残量で補いません。
- アカウントの取り違えを減らすため、残量取得時の確認を改善しました。履歴は既定で現在のアカウントに追従し、明示的に選んだ過去のアカウントは保持します。
- 利用には、ログイン済みの既存Claude設定フォルダとClaude Code 2.1.289以降が必要です。

## Deutsch

- Neue Einstellungen erlauben getrennte Claude-Kontoordner und die Auswahl des Ordners für die Menüleiste; Messwerte aller konfigurierten Ordner bleiben nach Konto getrennt. Fehlende Werte werden nicht durch andere Konten ersetzt.
- Verbesserte Kontoprüfungen beim Lesen der Kontingente verringern falsche Zuordnungen. Der Verlauf folgt standardmäßig dem aktuellen Konto und behält ausdrücklich gewählte frühere Konten bei.
- Erfordert vorhandene, bereits angemeldete Claude-Konfigurationsordner und Claude Code 2.1.289 oder neuer.

## 繁體中文

- 可分別設定現有 Claude 帳號資料夾，並選擇選單列使用的資料夾。各資料夾的有效額度會儲存為帳號獨立的歷史；缺少資料不會以其他帳號替代。

- 需要現有已登入的 Claude 設定資料夾及 Claude Code 2.1.289 或更新版本。
