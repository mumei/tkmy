# TKMY 1.0.11

## English

- Added a remaining-allowance history chart to the Claude Code popover, matching Codex. Switch between token usage and quota history, then select the 5-hour or 7-day window and chart period.
- The chart uses recorded remaining percentages and shows the last confirmed time. Missing data is not treated as 0% or 100%; the existing request-failure cache and reset-expiry rules remain in effect.
- Added regression coverage for both sources so the selected period and quota window survive refreshes and popover replacement. Related tests and the local app build passed. Real-account Claude retrieval remains unverified; the existing Claude Code 2.1.289-or-later requirement still applies.

## Tiếng Việt

- Đã thêm vào màn hình chi tiết Claude Code biểu đồ lịch sử hạn mức còn lại giống Codex. Có thể chuyển giữa mức sử dụng token và lịch sử hạn mức, rồi chọn khung 5 giờ hoặc 7 ngày và khoảng thời gian của biểu đồ.
- Biểu đồ dùng phần trăm còn lại đã ghi nhận và hiển thị thời điểm xác nhận gần nhất. Dữ liệu thiếu không được coi là 0% hoặc 100%; quy tắc bộ nhớ đệm khi yêu cầu thất bại và hết hạn lúc đặt lại vẫn giữ nguyên.
- Đã thêm kiểm thử hồi quy cho cả hai dịch vụ để xác nhận khoảng thời gian và khung hạn mức được giữ lại sau khi làm mới hoặc tạo lại màn hình. Các kiểm thử liên quan và bản dựng ứng dụng cục bộ đã thành công. Chưa xác minh việc lấy dữ liệu từ tài khoản Claude thật; vẫn yêu cầu Claude Code 2.1.289 trở lên.

## ไทย

- เพิ่มกราฟประวัติโควต้าที่เหลือในหน้ารายละเอียด Claude Code เช่นเดียวกับ Codex สลับระหว่างการใช้โทเค็นกับประวัติโควต้า แล้วเลือกโควต้าช่วง 5 ชั่วโมงหรือ 7 วันและช่วงเวลาของกราฟได้
- กราฟใช้เปอร์เซ็นต์ที่เหลือจากข้อมูลที่บันทึกไว้และแสดงเวลายืนยันล่าสุด ข้อมูลที่ขาดหายจะไม่ถูกถือเป็น 0% หรือ 100% กฎแคชเมื่อคำขอล้มเหลวและการหมดอายุเมื่อรีเซ็ตยังคงเดิม
- เพิ่มการทดสอบทั้งสองบริการเพื่อยืนยันว่าช่วงเวลาและโควต้าที่เลือกยังคงอยู่หลังรีเฟรชหรือสร้างหน้าจอใหม่ การทดสอบที่เกี่ยวข้องและการสร้างแอปในเครื่องผ่านแล้ว ยังไม่ได้ยืนยันการดึงข้อมูลจากบัญชี Claude จริง และยังต้องใช้ Claude Code 2.1.289 ขึ้นไป
