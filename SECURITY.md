# Security policy

Please do not report sensitive vulnerabilities in a public issue. Use GitHub's private vulnerability reporting for the repository that publishes TKMY.

Reports should include the affected version, reproduction steps, and impact. Never attach real prompt, response, source-code, project-path, API-key, or session-log data.

Official binaries are expected to be Developer ID signed, notarized by Apple, and distributed through an EdDSA-signed Sparkle appcast. Unsigned local builds are development artifacts.
