# Contributing

Issues and pull requests are welcome.

1. Do not commit real Codex or Claude Code logs.
2. Keep fixtures minimal and synthetic.
3. Run `swift test --disable-sandbox --scratch-path .build -Xcc -fmodules-cache-path=.build/ModuleCache`.
4. Explain any log-format assumption and add a fixture for it.
5. Keep pricing provenance and its update date with every catalog change.
