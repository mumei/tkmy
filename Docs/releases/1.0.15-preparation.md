## Scope and evidence

The reported Mac is a different computer. Its TKMY/CLI versions and account-switch tool remain unverified. The investigating Mac's old CLI, empty Claude quota tables and hidden Claude menu are not evidence of the target Mac's cause.

Orca is a plausible reference, not an established identity for the user's switching tool. Its account-folder migration removed shared credential replay ([PR 26801](https://github.com/stablyai/orca/pull/26801)); later shell routing work applies the chosen folder on the next Claude launch ([PR 29890](https://github.com/stablyai/orca/pull/29890)). TKMY previously launched one CLI context and could miss isolated folders.

The fix provides explicit references to existing configuration folders in Settings, independent identity/throttle/cache state per folder, history persistence for all configured accounts, and a selected folder supplying the current menu meter. A missing folder or unverified selection does not substitute another account's quota. Removing a reference stops polling it and preserves previously saved history. No automatic Orca discovery, credential file access, login, shared authentication switching or OAuth API migration is added. The existing CLI may manage its own credentials during normal operation; TKMY does not implement token refresh.

The exact usage child must report a matching initialized account before `get_usage` is sent. Before/after identity checks remain in force. SDK initialize metadata exposes an organization string that may be a display name, while `auth status` supplies the stable organization ID. The comparison accepts a matching ID or known display name and retains stable-ID checks before/after. Two organizations sharing both email and display name remain a contract limitation; a cross-process mismatch of that exact shape cannot be ruled out by these fields alone.

History now uses an explicit Follow current account choice. An automatic selection follows initial unknown-to-known recovery and later account changes; explicit historical or anonymous choices remain pinned. Token transcript ingestion keeps its existing roots; this change concerns allowance acquisition and history.
